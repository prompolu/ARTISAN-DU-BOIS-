# L'Artisan Du Bois — site web

Maquette de la page d'accueil pour **L'Artisan Du Bois**, fabricant de meubles en cèdre de l'Atlas et hêtre massif, sculptés à la main à Fès depuis 1993.

Direction artistique : ébène, or et cèdre.

## Contenu

- `index.html` : la page d'accueil (FR)
- `styles.css` : styles et responsive
- `main.js` : animations au défilement, menu mobile, sélecteur de coloris
- `assets/ig/` : photos des réalisations (Instagram @lartisan.du.bois)

## Voir le site

Ouvrir `index.html` dans un navigateur. Aucun outil de build n'est nécessaire.
